# Number Guessing Game

CLI-гра «Вгадай число» — рішення задачі [roadmap.sh/projects/number-guessing-game](https://roadmap.sh/projects/number-guessing-game).
Node.js ≥ 18, без залежностей. Рекорди зберігаються у `data/scores.json`
(інший шлях можна задати змінною `GUESSING_GAME_FILE`).

## Запуск

```bash
npm start            # або: node src/cli.js
npm test
```

Щоб запускати як `number-guessing-game`, виконай `npm link` у цій папці.

## Правила

Комп'ютер загадує число від 1 до 100. Обираєш складність, від якої залежить кількість спроб:

| Рівень | Спроби |
| ------ | ------ |
| Easy   | 10     |
| Medium | 5      |
| Hard   | 3      |

Після кожної помилки гра каже, чи загадане число більше або менше за твоє. Гра закінчується,
коли вгадав або спроби скінчилися.

## Додатково

- **Кілька раундів:** після раунду гра питає `Play again? (y/n)`.
- **Таймер:** після кожної здогадки показується, скільки секунд пішло, а після перемоги — час раунду.
- **Підказки:** введи `hint`. Перша підказка каже, парне число чи непарне, друга звужує до десятка.
  Підказки не забирають спроб.
- **Рекорди:** найменша кількість спроб для кожного рівня, зберігається між запусками.
- **Валідація:** не число, число поза 1–100 і неправильний вибір складності просто перепитуються й спроб не забирають.

## Структура

- `src/game.js` — правила без вводу-виводу (вибір числа, перевірка, підказки, рекорди)
- `src/play.js` — ігровий цикл; ввід і вивід передаються параметрами, тому гру можна програти в тесті
- `src/storage.js` — читання/запис рекордів у JSON
- `src/cli.js` — підключення до терміналу
- `test/` — `npm test` (вбудований `node:test`)
